# Hospital Patient Analytics Using SQL Server

## Project Overview

This project analyses a synthetic hospital dataset containing 10 patient records. The objective is to practise SQL querying and extract basic operational insights.

## Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* Git and GitHub

## Business Questions

1. What is the total billing amount?
2. What is the average patient age?
3. Which department has the highest total billing?
4. Which department has the highest average patient satisfaction?
5. Which patient records have bills above ₹20,000?

## SQL Concepts Demonstrated

* CREATE TABLE
* INSERT
* SELECT
* WHERE
* ORDER BY
* GROUP BY
* SUM()
* AVG()
* Aggregate calculations

## Key Findings

* Total billing across the sample: ₹220,000.
* Average patient age: 42.4 years.
* Cardiology has the highest total billing: ₹82,000.
* Neurology has the highest average satisfaction score: 4.67 out of 5.

## Limitations

The dataset contains only 10 synthetic records and is intended for learning purposes. The findings should not be generalised to real hospitals.

Billing amounts do not represent profit because operating costs have not been included.

## How to Run

1. Open SQL Server Management Studio.
2. Open `hospital_analysis.sql`.
3. Execute the script using F5.
4. Review the result sets generated by the queries.
